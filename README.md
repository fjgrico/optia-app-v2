# OPTIA V2 - Prueba de Gafas con IA

App para ópticas que permite probar gafas virtualmente con colocación automática mediante IA.

## Características

- Subida de foto del usuario
- Detección automática de ojos con MediaPipe
- Superposición inteligente de gafas (mockup)
- Descarga del resultado

## Instrucciones

1. Sube el proyecto a GitHub
2. Despliega en Streamlit Cloud (usa app.py como entry point)
3. Listo para testear con clientes reales

## Requisitos

- Python 3.9+
- streamlit
- opencv-python
- mediapipe
- Pillow
